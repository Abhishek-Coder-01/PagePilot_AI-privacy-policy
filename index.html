Privacy Policy

This Privacy Policy explains how the PagePilot AI Chrome Extension handles information when you use it. It is written in plain language so you know exactly what happens to your data.

Extension: PagePilot AI Developer: Abhishek Yadav Last updated: August 2026

1 Privacy Policy

This Privacy Policy applies to the PagePilot AI Chrome Extension ("the Extension", "PagePilot AI"), developed and maintained by Abhishek Yadav. By installing or using PagePilot AI, you agree to the practices described in this policy. If you do not agree with this policy, please do not install or use the Extension.

2 What PagePilot AI Does

PagePilot AI is a Chrome extension that helps you understand and interact with webpages using AI-powered analysis and local browser tools. Its features fall into two categories:

AI-powered features (require your Gemini API key):

  • Summarize webpages
  • Ask questions about the current webpage
  • Find buttons on the page
  • List key links
  • Explain forms
  • Generate key takeaways
  • Explain webpage code

Local browser tools (no AI, no internet request required):

  • Download Images
  • Inspect Element
  • Remove Ads / Clean Page

3 Information We Process

PagePilot AI processes only the information necessary to provide its features:

  • Webpage content: When you use an AI-powered feature, relevant content from the currently open webpage (such as visible text, links, form fields, or code) may be processed in order to generate a response.
  • Gemini API key: You provide your own Google Gemini API key. This key is stored locally on your device/browser and is used to authenticate requests to the Gemini API.
  • Locally processed page data: Local tools (Download Images, Inspect Element, Remove Ads / Clean Page) read and process webpage information directly in your browser, without sending it anywhere.

PagePilot AI does not require you to create an account, and does not ask for personal information such as your name, email address, or payment details.

4 How Information Is Used

Information processed by PagePilot AI is used solely to:

  • Generate AI-powered responses (summaries, answers, explanations, takeaways, etc.) for the webpage you are viewing.
  • Authenticate your requests to the Google Gemini API using your stored API key.
  • Perform local, on-device actions such as downloading images, inspecting page elements, or cleaning a page of ads.

PagePilot AI does not use your data for advertising, analytics, profiling, or any purpose unrelated to the feature you actively used.

5 Google Gemini API

PagePilot AI's AI-powered features are built on the Google Gemini API. When you use an AI feature, the relevant webpage content and your request are sent directly from your browser to Google's Gemini API, using the API key you provided, in order to generate a response.

Your Gemini API key is used to make these requests but is not sent to or stored on any server operated by the developer of PagePilot AI. It is used only to communicate directly with Google's Gemini API on your behalf.

Because Gemini is a third-party AI service provided by Google, any webpage content submitted through an AI feature is subject to Google's own data handling and privacy practices. We encourage you to review Google's privacy documentation for details on how Google processes API requests:

Google Privacy Policy  ·  Gemini API Additional Terms of Service

In short: your API key is used to talk to Gemini, not to our servers — because PagePilot AI does not operate a backend server.

6 Local Browser Tools

The following features operate entirely within your browser and do not send any data to the Gemini API or to any external server:

  • Download Images — detects and downloads images from the current page locally.
  • Inspect Element — lets you view the underlying HTML/CSS of page elements locally.
  • Remove Ads / Clean Page — removes or hides selected elements from the page view locally.

These tools work by directly manipulating or reading the webpage's DOM inside your browser tab. No network request is made when you use these local tools.

7 Data Storage and Retention

  • API key: Stored locally in your browser's extension storage (e.g. Chrome's local storage for extensions). It stays on your device and is not transmitted to any server operated by PagePilot AI.
  • Webpage content used for AI features: Processed temporarily to generate a response and is not permanently stored by PagePilot AI. PagePilot AI does not operate a database or backend server, so no long-term storage of your webpage content occurs on our end.
  • Local tool data: Processed and used directly within your browser session and is not stored beyond what is needed to perform the requested local action (e.g. saving a downloaded image to your device).

Any handling or retention of data by Google's Gemini API once a request is sent is governed by Google's own privacy policy, not by PagePilot AI.

8 Data Sharing

  • We do not sell your data. PagePilot AI does not sell, rent, or trade user data to any third party.
  • Google Gemini API: The only third-party service PagePilot AI interacts with is Google's Gemini API, used solely to power the AI features you actively choose to use.
  • PagePilot AI does not share your data with advertisers, analytics providers, or any other third party, because no such integrations exist in the Extension.

9 Data Security

Your Gemini API key is stored locally within your browser's extension storage rather than on any remote server, which limits its exposure. However, no method of local storage or data transmission over the internet is completely secure, and PagePilot AI cannot guarantee absolute security.

You are responsible for keeping your device and browser secure, and for safeguarding your own Gemini API key, in the same way you would with any other API credential.

10 User Choices and Control

  • You can add, update, or remove your Gemini API key at any time from the Extension's settings.
  • You can choose to use only the local tools (Download Images, Inspect Element, Remove Ads / Clean Page) without ever providing an API key.
  • You can stop using any AI-powered feature at any time — simply not invoking that feature means no webpage content is sent to the Gemini API.
  • You can uninstall the Extension at any time via chrome://extensions, which removes the locally stored API key and any extension data from your browser.

11 Children's Privacy

PagePilot AI is not directed at children and is not intended for use by individuals under the age of 13 (or the minimum age required by your jurisdiction). We do not knowingly collect personal information from children. If you believe a child has provided information through the Extension, please contact us so it can be addressed.

This Privacy Policy may be updated from time to time to reflect changes in the Extension's functionality or for legal and regulatory reasons. Any changes will be posted on this page with an updated "Last updated" date. Continued use of PagePilot AI after changes are posted constitutes acceptance of the revised policy.
